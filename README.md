# Progressing —— 每天陪你完成计划的时间进度条

**Progressing** 是一个常驻桌面角落的"每日时间进度条"工具：它把一天 24 小时画成一条进度条，用一个箭头（指针）标出现在的时刻，让"今天还剩多少时间"一眼就能看到。

- 进度条横着或竖着放在桌面上，**不抢焦点、不挡鼠标**（点击会直接穿透到桌面）。
- 它平时躲在右下角**托盘图标**里，完全不打扰你。
- 你可以在进度条上**给一天分段上色并写备注**，比如"工作 9:00–12:00"、"午休 12:00–13:30"。
- 所有数据只保存在**你自己的电脑上**，不联网、不上传、不注册账号。

> 本文件写给**不熟悉电脑编程**的朋友。请按下面的顺序一步步来，遇到任何看不懂的词都有解释。

---

## 一、使用前需要准备什么

Progressing 是给 **Windows** 电脑用的。

1. **操作系统**：Windows 10 或 Windows 11。
2. **拿到程序**：二选一（见下文"第二步"）：
   - **方式 A**：下载现成的程序包 —— 最省事，什么都不用装。
   - **方式 B**：自己动手编译 —— 需要安装一个免费的开发工具。

> 小贴士：这个仓库目前是**源代码**（就是"程序的原始图纸"）。如果你不会编译，建议先联系作者要一份已经编译好的程序包，或者找身边懂电脑的朋友帮忙按"方式 B"操作一次，以后就能一直用了。

## 二、拿到程序（两种方式任选）

### 方式 A：下载现成的程序包（最省事，推荐）

1. 从作者提供的下载地址（或发布页面）下载压缩包，比如 `Progressing-1.0.zip`。
2. 右键压缩包 → **全部解压缩**（解压到一个固定的文件夹，比如 `D:\Progressing`）。
3. 打开解压后的文件夹，找到 **`Progressing.exe`**，**双击**它。

> 如果作者打包成了**安装程序**（比如 `Progressing-Setup.exe`），直接双击按提示安装即可，安装完在桌面或开始菜单找"Progressing"图标打开。

### 方式 B：自己动手编译（大约 10 分钟）

这种方式需要先装一个免费的微软开发工具 —— **.NET SDK**。

1. **安装 .NET SDK 10**
   - 打开浏览器，访问微软官网的 .NET 下载页面：
     `https://dotnet.microsoft.com/download/dotnet/10.0`
   - 找到 **.NET SDK 10.x**（注意：是 SDK，不是"运行时"），下载 Windows x64 版本，双击安装，一路"下一步"即可。

2. **生成可直接双击运行的程序**（一步到位，之后无需再装任何东西）
   - 打开本仓库的根目录（就是存放 `README.md` 的文件夹，比如 `D:\Progressing`）。
   - 在地址栏输入 `powershell` 并按回车，会打开一个黑色（或蓝色）的命令窗口。
   - 把下面这行字**完整复制**进去，按回车，等待显示"已成功生成"：

     ```powershell
     dotnet publish src\Progressing\Progressing.csproj -c Release -r win-x64 --self-contained true
     ```

   - 完成后，打开文件夹：
     `src\Progressing\bin\Release\net10.0-windows\win-x64\publish\`
   - 里面就有 **`Progressing.exe`**，**双击**即可运行。这个文件夹里的东西**都可以随意移动**（比如拷到桌面或 U 盘），拷走也能用。

> 想临时快速试一下？也可以直接运行上面那条命令的"调试版"：`dotnet run --project src\Progressing`（窗口关掉程序就停了，只适合体验，日常用请用方式 A 或发布版）。

## 三、第一次启动，认识一下

1. 双击 **`Progressing.exe`**。
2. 桌面上会出现一条**浅灰色的进度条**，上面还有一个小箭头 —— 这就是今天的时间进度。
   - 箭头位置 = 现在的时刻。比如箭头在整条的四分之一处，说明今天已经过了 6 个小时（6 点）。
   - 整条进度条 = 一整天 24 小时。
3. 屏幕**右下角**（任务栏最右侧，时钟旁边）会出现一个**小图标**，这就是**托盘图标**，它是这个程序的总开关。
   - 如果看不到，点一下时钟左边的"^"小箭头，把它拖出来。
4. 第一次启动，右下角会弹出一个气泡："右键托盘图标开始配置"。
   - **右键**点击托盘图标，会弹出菜单：

     | 菜单项 | 作用 |
     |---|---|
     | 新建进度条 | 立刻再做一个新的进度条（最多 16 条） |
     | 打开设置 | 打开设置窗口（就是接下来要学的） |
     | 退出 | 完全关闭 Progressing |

## 四、按你的喜好设置进度条

### 怎么打开设置窗口

任意一种都行：

- **右键托盘图标 → 打开设置**；
- **左键单击托盘图标**（最方便）；
- 进度条本身平时不能点（会穿透），所以请用上面两种方式。

### 设置窗口长什么样

窗口顶部是一排**标签**（像浏览器标签页）：

```
[ 全局 ] [ 进度条 1 ] [ 进度条 2 ]  ＋
```

- **全局**：整个程序的设置（开机自启、版本等）。
- **进度条 1 / 进度条 2 ...**：每一条进度条自己的设置，一条一个标签。
- 点"**＋**"可以新建进度条（自动命名"进度条 N"并让你改名）。
- **右键**某个进度条标签，可以 **重命名 / 复制 / 删除** 这条进度条（最后一条不允许删除）。

选中一个进度条标签后，窗口左边有一列分区导航，点哪个就看哪个：

#### 1. 外观 —— 让它"看起来"合你心意
| 选项 | 说明 |
|---|---|
| 显示进度条 | 取消勾选 = 暂时把这条进度条藏起来 |
| 置顶显示 | 勾选后进度条会盖在其它窗口上面，永远看得见 |
| 透明度 | 拖动滑块调整透明程度（0 = 全透明，100 = 完全不透明） |
| 边框 | 给进度条加一圈描边，并可选择描边颜色 |

#### 2. 位置 —— 让它"待在"你指定的地方
| 选项 | 说明 |
|---|---|
| 方向 | 横放（从左到右）或竖放（从上到下） |
| 镜像时间轴 | 勾选后时间从右往左 / 从下往上走（一般不需要） |
| 长度 / 宽度 | 拖动滑块调整进度条的长短和粗细 |
| 快速定位 | 选"顶部居中 / 底部居中 / 左侧居中 / 右侧居中"，立即跳到对应屏幕位置；旁边可选"显示器"（插了多台显示器时用） |
| X / Y | 精确调整坐标；点旁边的 ◀ ▶ ▲ ▼ 小按钮微调（按住不放会连续移动） |
| 进入位置编辑模式 | 开启后进度条变清晰，可以直接**用鼠标拖动**进度条和备注文字，拖完点"完成" |

#### 3. 指针 —— 现在"几点了"的那个箭头
| 选项 | 说明 |
|---|---|
| 图标来源 | 内置（自带的箭头）或自定义文件（选一个 .png / .svg 图片） |
| 文件 | 选择自定义图片的路径（点"浏览…"） |
| 大小 | 指针图标的大小 |
| 横放指向 / 竖放指向 | 箭头朝哪个方向（向上/向下、向左/向右） |

#### 4. 时间段 —— 给一天上色、写备注（最有用的功能）
点"**＋ 添加时间段**"，会出现一行输入框：

```
[开始时间 09:00] [结束时间 12:00] [备注文字：工作] [颜色] [↑] [↓] [✕]
```

- 起止时间填写 24 小时制，比如早上 9 点写 `09:00`，下午 3 点写 `15:00`。
- 填好备注文字、选个颜色，进度条上对应位置就会显示**彩色的一段**，指针走到这里时还会在旁边显示备注文字。
- 点颜色按钮会打开取色面板：从色池选一个、或用**最近使用**的颜色、或自己调一个（拖动色相/深浅，或直接输入 `#4A90D9` 这种颜色代码）。
- 点 **↑ / ↓** 调整这条时间段的先后顺序，点 **✕** 删除。
- **注意**：同一条进度条上，时间段不能互相重叠（比如"9:00–12:00"和"10:00–11:00"就不行）。如果填了重叠的时间，会弹出提示，按提示操作即可。

#### 5. 文字样式 —— 备注文字长什么样
| 选项 | 说明 |
|---|---|
| 基准方向 | 备注文字出现在进度条的哪个方向（上方/下方/左侧/右侧） |
| 排列方向 | 文字横着写还是竖着写 |
| 文字颜色 / 文字边框 | 备注文字的颜色，以及是否加一圈描边让文字更清楚 |

#### 6. 其它
- **恢复默认配置**：把这条进度条的所有设置还原成刚安装时的样子（备注会被清空，请慎用）。

### 全局页（第一个标签）
| 选项 | 说明 |
|---|---|
| 开机自启 | 勾选后，每次打开电脑自动运行 Progressing（不需要手动双击了） |
| 最近使用颜色 | 你在取色面板里用过的颜色，会保存在这里方便下次选 |
| 版本 | 当前程序版本号 |

## 五、日常使用小贴士

- **怎么看进度**：指针到彩色段的起始处 = 那个时间段开始了；指针走过彩色段 = 这段时间正在进行。
- **想同时管好几件事**：点"＋"新建多条进度条（比如一条管工作、一条管学习），每条可以放在屏幕不同位置。
- **换了显示器或分辨率**：到"位置"分区重新点一次"快速定位"，或进入"位置编辑模式"用鼠标拖一下即可。
- **关闭设置窗口**：点右上角"X"只是把设置窗口关掉，**程序仍然在托盘里继续跑**，进度条照常更新。想完全退出请**右键托盘图标 → 退出**。
- **重启后想继续用**：在"全局"页勾选"开机自启"。

## 六、数据存在哪里 / 想重置怎么办

- 你的所有设置（进度条、颜色、备注、位置）都保存在一个配置文件里：
  `C:\Users\你的用户名\AppData\Roaming\Progressing\config.json`
  （看不到"AppData"？在文件资源管理器地址栏直接复制粘贴这行地址即可。）
- **想彻底重置**：先右键托盘图标 → 退出，然后删掉上面这个 `config.json` 文件，再启动程序，就会像第一次使用一样。
- 只要不删这个文件，你的设置一直都在；重装程序、升级版本都不影响它。

## 七、常见问题（FAQ）

**问：进度条不见了？**
答：右键托盘图标 → 打开设置 → 选中对应标签 → "外观"分区，确认勾选了"显示进度条"。如果还不行，多半是程序没在运行，重新双击 `Progressing.exe` 即可。

**问：托盘图标也不见了？**
答：程序可能没启动，或者被系统收起来了。点任务栏最右侧的"^"小箭头，看图标是否藏在里面；也可以重新双击 `Progressing.exe`。

**问：双击程序弹出错误，说缺少 .NET？**
答：你用的是"方式 B"编译版但没装运行环境。两个解决办法：请作者提供"方式 A"的现成程序包；或重新用上面"方式 B"的**自包含**命令（`--self-contained true`）编译，那种版本不依赖任何环境，拷走就能用。

**问：时间段填完怎么不见了？**
答：先检查起止时间是否填对（比如开始 15:00、结束 14:00 会不合法）；再确认没有和其它时间段重叠。填好并**离开输入框**后就会生效。

**问：进度条挡住我想点的东西了？**
答：进度条默认是"点击穿透"的——鼠标点它等于点桌面，不会挡任何操作。只有进入"位置编辑模式"时才能用鼠标拖动它。

**问：最多能建几条进度条？**
答：16 条。到上限后"＋"按钮不会再生效。
